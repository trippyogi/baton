# ADR 008 — Node 24 during TypeScript migration

Status: Accepted  
Date: 2026-08-07

## Decision

Move from Node 20 to Node 24 in Phase 1. Pin major in `engines`, `.nvmrc`, CI, and docs.

## Rationale

Platform migration is already occurring; carrying Node 20 only forces a second infra upgrade.

## Consequences

- Validate native modules (`better-sqlite3`) early.
- Docs/scripts that mention Node 20 are updated in Phase 1.
